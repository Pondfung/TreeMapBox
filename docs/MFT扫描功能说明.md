# MFT扫描功能说明

## 功能概述

MFT（Master File Table）扫描是一种极速扫描技术，通过直接读取NTFS文件系统的索引表，可以在**10-15秒内完成整个系统盘的扫描**，比传统扫描快20-50倍。

## 使用方法

### 1. 在主窗口选择扫描模式

在扫描模式下拉框中，有以下选项：

- **自动（推荐）**：优先使用MFT扫描，失败则降级为普通扫描
- **MFT极速扫描**：强制使用MFT扫描（需要管理员权限）
- **普通扫描**：使用传统的文件遍历方式

### 2. 以管理员身份运行（推荐）

MFT扫描需要管理员权限。使用方法：

```bash
# Windows: 右键点击程序 -> "以管理员身份运行"
# 或者使用命令行：
python main.py
```

## 技术实现

### 核心组件

1. **MFTScanner** (`core/mft_scanner.py`)
   - 直接读取NTFS MFT表
   - 需要管理员权限
   - 仅支持Windows NTFS

2. **HybridScanner** (`core/mft_scanner.py`)
   - 混合扫描器
   - 自动选择最佳扫描方式
   - MFT失败时自动降级

### 依赖安装

```bash
# 可选依赖：python-ntfs（用于MFT扫描）
pip install python-ntfs

# 或者使用pywin32（Windows API）
pip install pywin32
```

## 性能对比

| 扫描方式 | 系统盘扫描时间 | 权限要求 | 支持平台 |
|---------|--------------|---------|---------|
| MFT扫描 | **10-15秒** | 管理员 | Windows NTFS |
| 普通扫描 | 2-5分钟 | 普通用户 | 所有平台 |

## 优缺点分析

### ✅ 优点

1. **极速扫描**：10-15秒完成整个盘（传统方式需要2-5分钟）
2. **不受目录层级影响**：所有文件都是平等记录，速度一致
3. **可访问已删除文件记录**（未覆盖前）

### ❌ 缺点

1. **必须管理员权限**
2. **仅支持Windows NTFS**（不支持FAT32、exFAT）
3. **实现复杂**：需要理解NTFS文件系统结构
4. **无法获取实时权限信息**

## 注意事项

1. **首次使用建议选择"自动"模式**，系统会自动选择最佳扫描方式
2. **如果提示需要管理员权限**，请右键以管理员身份运行程序
3. **非NTFS分区（如U盘）**会自动使用普通扫描
4. **扫描深度设置对MFT扫描无效**（MFT扫描会扫描所有文件）

## 故障排除

### 问题1：提示"需要管理员权限"

**解决方法**：右键点击程序或命令行，选择"以管理员身份运行"

### 问题2：MFT扫描失败，自动降级

**原因**：
- 没有安装python-ntfs库
- 不是NTFS文件系统
- 其他技术错误

**解决方法**：系统会自动降级到普通扫描，无需手动处理

### 问题3：扫描速度仍然很慢

**可能原因**：
- 当前不是MFT扫描（检查扫描方法显示）
- 目标分区不是NTFS

**解决方法**：确认扫描方法显示为"MFT极速扫描"

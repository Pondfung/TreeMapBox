# 打包说明

## 打包方法

### 方法1：使用PyInstaller命令行（推荐）

```bash
# 在项目根目录运行：
pyinstaller --name="TreeMapBox" --onefile --windowed --clean --noconfirm --add-data="config;config" --add-data="core;core" --add-data="ui;ui" --hidden-import=PyQt6 --hidden-import=PyQt6.QtCore --hidden-import=PyQt6.QtGui --hidden-import=PyQt6.QtWidgets --hidden-import=send2trash main.py
```

### 方法2：使用打包脚本

```bash
python build_exe.py
```

## 打包参数说明

- `--name`: 设置程序名称
- `--onefile`: 打包成单个exe文件
- `--windowed`: 窗口模式（不显示控制台）
- `--clean`: 清理临时文件
- `--noconfirm`: 不询问确认
- `--add-data`: 添加数据文件（格式：源路径;目标路径）
- `--hidden-import`: 添加隐藏导入的模块

## 输出位置

打包后的exe文件位于：
```
dist/TreeMapBox.exe
```

## 注意事项

1. **首次打包时间较长**：PyInstaller需要分析所有依赖，可能需要3-5分钟
2. **exe文件较大**：包含了Python运行时和所有依赖，约30-50MB
3. **需要管理员权限**：运行exe时需要右键"以管理员身份运行"才能使用MFT扫描

## 常见问题

### 问题1：打包失败，提示缺少模块

**解决方法**：添加 `--hidden-import` 参数

```bash
--hidden-import=模块名
```

### 问题2：exe运行时缺少文件

**解决方法**：添加 `--add-data` 参数

```bash
--add-data="源路径;目标路径"
```

### 问题3：exe文件太大

**解决方法**：
- 使用 `--exclude-module` 排除不需要的模块
- 或者使用目录模式（`--onedir`）代替单文件模式（`--onefile`）

## 运行要求

1. **Windows 10/11**
2. **管理员权限**（用于MFT扫描）
3. **NTFS文件系统**（用于MFT扫描）

## 使用方法

1. 右键点击exe文件
2. 选择"以管理员身份运行"
3. 选择扫描路径和扫描模式
4. 点击"开始扫描"

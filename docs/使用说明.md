# TreeMapBox - 使用说明

## 快速开始

### 1. 运行程序
右键点击"TreeMapBox.exe"，选择"以管理员身份运行"

### 2. 选择扫描路径
输入或浏览选择要扫描的目录（如 C:\）

### 3. 选择扫描模式
- **自动（推荐）**：优先尝试MFT极速扫描，失败则自动降级为普通扫描
- **MFT极速扫描**：10-15秒完成（需要额外安装python-ntfs库）
- **普通扫描**：2-5分钟完成（无需额外依赖）

### 4. 开始扫描
点击"开始扫描"按钮

## 扫描模式详解

### 自动模式（推荐）
- 优先尝试MFT极速扫描
- 如果MFT扫描不可用，自动降级为普通扫描
- 适合大多数用户

### MFT极速扫描
**优点**：速度快（10-15秒扫描整个盘）
**限制**：
1. 需要管理员权限
2. 仅支持Windows NTFS文件系统
3. **需要安装python-ntfs库**（见下方说明）

### 普通扫描
**优点**：无需额外依赖，稳定可靠
**缺点**：速度较慢（2-5分钟）

## MFT极速扫描配置（可选）

如果需要使用MFT极速扫描，需要安装额外依赖：

### 方法1：直接安装（推荐）
```bash
pip install python-ntfs
```

### 方法2：使用requirements安装
```bash
pip install -r requirements.txt
```

**注意**：如果不安装python-ntfs库，建议使用"自动"或"普通扫描"模式。

## 矩形树图使用

### 基本操作
- **展开目录**：点击左侧树形列表的目录
- **双击钻取**：双击右侧矩形进入子目录
- **返回上级**：右键菜单 -> 返回上一级
- **返回根目录**：右键菜单 -> 返回根目录

### 颜色说明
- **蓝色系**：普通文件/目录
- **悬停高亮**：鼠标悬停时颜色变亮

### 大小比例
- 矩形大小按排名分配（最大15倍差距）
- 确保所有文件都能清晰可见

## 常见问题

### Q: 为什么MFT极速扫描会失败？
A: 可能原因：
1. 没有管理员权限
2. 没有安装python-ntfs库
3. 目标分区不是NTFS格式

**解决方法**：使用"自动"模式，会自动降级为普通扫描

### Q: 扫描速度很慢怎么办？
A:
1. 减少扫描深度（选择"浅层扫描"）
2. 扫描更小的目录（如 C:\Users 而不是 C:\）
3. 以管理员身份运行并安装python-ntfs库

### Q: 如何删除文件？
A:
1. 在左侧树形列表中右键点击
2. 选择"删除"或"批量删除"
3. 文件会被移到回收站

### Q: 扫描结果不准确？
A:
1. 某些系统目录可能需要管理员权限才能访问
2. 某些文件可能被其他程序锁定
3. 建议以管理员身份运行程序

## 技术支持

1. 是否以管理员身份运行
2. 扫描路径是否存在
3. 扫描模式是否正确选择

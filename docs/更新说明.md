# 更新说明

> 当前版本 v0.9.5（2026-08-25）。完整功能列表与已知问题见根目录 `readme.md` 的「版本历史」。

## v0.9.5（2026-08-25）

### 新增
- **Tab 框架**（QTabWidget）：磁盘分析 → 重复文件 → 缓存清理
- **缓存清理 Tab**：9 大类 54 个缓存路径扫描、三级安全评级、双树布局（安全/谨慎危险分区）、自选目录扫描、分类过滤
- **重复文件筛选 Tab**：三级渐进式哈希比对（大小→三点采样→完整）、多线程并行、SQLite 哈希缓存、硬链接替换、保留策略、双树隔离显示
- **磁盘分析 Tab JSON 导出**：根目录扫描自动按盘符导出 JSON（原子写），供重复文件 Tab 复用；1 天内 JSON 弹窗询问复用或重扫

### 修复
- 重复文件扫描大目录后闪退（`datetime.fromtimestamp` 异常未捕获 + windowed 级联崩溃、排序竞态、QThread 生命周期、SQLite 并发卡死）
- 复选框样式/居中/勾选状态错乱：改用 Qt 原生 CheckStateRole + CE_CheckBox 居中 delegate、禁用树形缩进、int 比较 CheckState
- JSON 导出失败导致每次重新扫描：含 surrogate 代理字符路径编码失败（C 盘根因）+ 导出异常被静默吞掉——原子写 + `_safe_path` 代理安全化 + 失败可见化
- JSON 加载后树双份/切盘混入：`_load_from_json` 重建前未清空旧树
- 扫描/哈希/路径扫描取消卡死：各阶段循环内检查取消标志 + 取消后 emit finished 收尾

### 已知限制
- 导出的 JSON 不含 `mtime`，树中修改时间来自实时 `os.path.getmtime()`
- 哈希缓存批量提交（每 50 次）可能丢失每个工作线程最后不足 50 条的写入（下次扫描重算，不影响正确性）
- 跳过缓存/临时文件按路径各级目录名匹配，路径中恰好含这些子串的合法目录也会被跳过（可取消勾选关闭）
- MFT 极速扫描需管理员权限 + pyfsntfs 库，否则降级普通扫描
